# Security policy

This policy applies to public repositories of securagen.ai that do not contain their own `SECURITY.md`.

## Reporting a vulnerability

Please **do not** report security issues through public GitHub issues, pull requests or discussions.

Report privately in one of these ways:

1. **GitHub private vulnerability reporting** (preferred): open the affected repository, go to the **Security** tab and select **Report a vulnerability**.
2. **E-mail**: [contact@securagen.ai](mailto:contact@securagen.ai), with the subject line `Security report: <repository name>`.

Please include the affected repository and commit, a description of the issue and its impact, and the steps needed to reproduce it. Do not include classified, special-category or highly confidential information without prior coordination.

## What to expect

We will acknowledge your report, keep you informed while we investigate, and coordinate the timing of any public disclosure with you. We ask that you give us a reasonable opportunity to address the issue before disclosing it publicly.

## Scope

This policy covers the code and documentation published in our public repositories. Research artifacts, such as reproducibility packages, are provided for scientific verification and are not production software. Reports about third-party dependencies or external datasets should also be sent to their respective maintainers.
